## Appendix 5. FEATURE-TO-MODEL MAPPING

| Feature Group | CNN Text Component | URL Feature Component | Random Forest Component | FiLM Generator and Classification |
|---|---|---|---|---|
| SMS Text | Processes SMS messages using trainable fastText embeddings and a one-dimensional CNN with 64 convolutional filters | Not applicable | Not applicable | Provides textual feature representations for conditioning and classification |
| URL Structural Features | Not directly processed by the CNN text encoder | Extracts 37 URL structural features covering URL shape, URL words, webpage, and domain characteristics | Processes the 37 URL structural features to generate link-related predictions | Not read directly; reaches the generator only through the Random Forest's P and u |
| CNN Feature Representations | Generates 64 convolutional feature maps | Not applicable | Not applicable | The generator reads the average of each of the 64 convolution maps over all positions (before activation); the classifier reads the 64 max-pooled activations after FiLM |

## Corrections to the template text

The fixed text of the template was checked against the code and the data; these rows differ from the template:

1. **Table 1.4, False Negative.** The template says "Negative cases incorrectly predicted as negative". A false negative is a POSITIVE case predicted as negative.
2. **Table 1.2, KNN-RF-ETC voting.** The model routes by link (Jain et al., 2022; src/unified/voting_baseline.py): only messages WITHOUT a link go to the TF-IDF + SMOTE + KNN/RF/Extra Trees vote; messages WITH a link are classified from the link string alone by a Logistic Regression on CountVectorizer tokens. The template mentions only the text route.
3. **Table 1.2, Proposed.** has_url is not an input of the generator: the generator reads P, u, page_missing and the 64 convolution averages; has_url only switches FiLM off (γ = 1, β = 0) for messages without a link.
4. **Table 1.2, Concatenation and CNN-only.** page_missing and has_url are not Random Forest outputs (only P and u are). The CNN-only branch also log-scales long-tailed counts and adds missing-value flags (src/features/model/raw_cnn.py).
5. **Appendix 4, page_missing.** The template says "0 = reached or no URL". In the data and the code a message with no URL has page_missing = 1 (all 888 no-link messages): 1 = not reached or no URL; 0 = reached.
6. **Appendix 4, u.** u is the standard deviation of the 200 trees' probabilities (src/features/model/rf_extractor.p_and_u), so its range is 0–0.5, not 0–1.
7. **Appendix 4, domain_in_title.** Inverted in the template. The lab follows the public dataset's rule: 1 when the domain is NOT in the title, 0 when it is (src/lejet/features/html_features.py).
8. **Appendix 4, domain_with_copyright.** Inverted in the template. 1 = a copyright/trademark mark exists and the domain is NOT within 50 characters of it; 0 = no mark, or the domain is next to it.
9. **Appendix 4, safe_anchor.** Unsafe anchors are links containing "#", "javascript" or "mailto" (not links to another domain), and the value is a percentage 0–100 (docs/hannousse_87_features.md).
10. **Appendix 4, links_in_tags / ratio_intMedia / ratio_extMedia.** Percentages 0–100 (the public dataset's scale), not ratios 0–1. ratio_intHyperlinks is the only 0–1 ratio among the page features.
11. **Appendix 4, missing values.** −1 means not measured: every webpage feature is −1 when the page was not reached, the domain features are −1 when the RDAP lookup failed, and nb_redirection is −1 when the redirect chain was not recorded. nb_redirection reaches 9 in the data (eight followed hops plus an app-store hand-off).
12. **Appendix 5, CNN Feature Representations.** The generator does not receive the 64 pooled activations: it reads the average of each convolution map over all positions, taken before activation (src/features/model/film_cnn.py, conv_average). The classifier reads the 64 max-pooled activations after FiLM.
