How the forest scored this link

Each row is a feature of the link or its page and how many probability points it pushed the forest's score up (+, toward phishing) or down (−). The model receives this breakdown as its link input.

What moved the verdict

Contribution: how far each input pushed the score toward the final verdict (red toward smishing, green away). Gate: the fixed Random-Forest-derived weight on that input.
